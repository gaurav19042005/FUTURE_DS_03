# 📊 Marketing Funnel & Conversion Performance Analysis

This project analyzes user behavior across a website marketing funnel using **Power BI**.  
The goal is to identify **conversion rates, user drop-offs, and opportunities to improve the customer journey.**

---

## 🚀 Project Overview

A marketing funnel helps businesses understand how users move from **visiting a website to completing a purchase**.

This dashboard analyzes each stage of the funnel and highlights where users drop off.

### Funnel Stages

Visitors → Home Page → Search Page → Payment Page → Purchase

---

## 📂 Dataset

The dataset contains user activity across different funnel stages.

**Files used:**

- `user_table.csv`
- `home_page_table.csv`
- `search_page_table.csv`
- `payment_page_table.csv`
- `payment_confirmation_table.csv`

These datasets were merged to create a unified dataset for analysis.

---

## 📈 Key Insights

- Total Visitors: **90,000**
- Search Users: **45,000**
- Payment Users: **6,030**
- Purchases: **452**
- Overall Conversion Rate: **~0.5%**

### Drop-Off Analysis

The largest drop occurs between:

Search Page → Payment Page

This indicates potential issues with:

- checkout process
- pricing visibility
- user experience

---

## 💡 Recommendations

- Simplify checkout steps
- Improve website speed
- Optimize mobile user experience
- Reduce friction in the payment process
